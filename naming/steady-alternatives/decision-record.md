# Decision Record: ADHD CBT App Rebrand — Final Three

**Date:** 2026-08-16  
**Decision:** Advance **Pace**, **Steady**, **Ballast** to mockup testing (Phase 4).  
**Dissents:** None — unanimous on three-way final.

## Rationale

- **Pace** embeds the anti-pressure promise directly: **“ADHD CBT, at your pace”** makes the name and subtitle a single coherent sentence.
- **Steady** wins on immediate consumer recognition: calm, stable, approachable, with the lowest cognitive load at first glance.
- **Ballast** wins on distinctiveness and defensibility: a nautical metaphor for unseen stabilization maps naturally to CBT's supportive role.

## Mockup Test

Create three identical mockups using the same logo system, screens, typography, layout, and primary color. Vary only the app name and subtitle.

| Variable | Steady | Pace | Ballast |
|---|---|---|---|
| App name | **Steady** | **Pace** | **Ballast** |
| Subtitle (EN) | ADHD CBT, at your pace | ADHD CBT, at your pace | ADHD CBT, without the pressure |
| Subtitle (TR) | ADHD CBT, kendi hızında | ADHD CBT, kendi hızında | ADHD CBT, baskı yok |
| Logo | Brain-leaf mark | Brain-leaf mark | Brain-leaf mark |
| Primary color | `#2F5FD0` | `#2F5FD0` | `#2F5FD0` |

### Blind-test protocol

1. Show the home screen for 5 seconds → **“What's the app name?”**
2. Show the session screen for 5 seconds → **“What does this app do?”**
3. After 24 hours → **“What was the app name?”** and **“How did it feel?”**

### Success criteria

- >60% unaided name recall.
- Vibe description aligns with **calm, non-judgmental, no pressure**.

## Next Actions

1. Build the three blind mockups with identical UI and branding system except for name/subtitle.
2. Run the 5–7 participant target-user test (ADHD diagnosis, age 18–45) using the protocol above.
3. Run trademark, domain, app-store, linguistic, and social validation in parallel.
4. Compile mockup results and validation findings.
5. Make the final single-name decision after both evidence sets are complete.
