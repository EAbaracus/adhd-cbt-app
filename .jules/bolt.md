## 2024-05-24 - Batch SQLite Sync Upserts
**Learning:** For F2 backend's periodic synchronization feature (`/api/sync/backup`), the client uploads large payloads containing many user data items (progress, logs, etc.). Initially, `store.conn.execute()` was called in a `for` loop, incurring a high Python-to-SQLite transition overhead per item. SQLite allows bulk upserts with `.executemany()`. The Python `sqlite3` driver properly parses row counts from `executemany` which makes it ideal for bulk DB ops without missing counts.
**Action:** Always prefer `executemany` over loop-based `execute` calls when saving or updating multiple items from a sync or batch payload in SQLite, as it effectively halves the operation time while maintaining single-statement atomicity and correctly returning `rowcount`.
